# How-Tos

Task-oriented guides for building with jEAP — "how do I accomplish X" — grouped by topic rather than
by repository. Each page links to a how-to that already lives with the component it covers (the page
itself is not duplicated here; this is an index).

## Categories

- [Security](security/index.md) — authentication, tokens, roles, TLS, encryption, signing, test tooling
- [Messaging](messaging/index.md) — Kafka, message types, contracts, outbox, error handling, process archive/context
- [REST APIs & Web](rest-apis-and-web/index.md) — HTTP APIs, OpenAPI publishing, server-sent events
- [Backend & Data](backend-and-data/index.md) — databases, migrations, OpenSearch
- [Architecture & Observability](architecture-and-observability/index.md) — architecture repo, deployment log, reaction tracking, governance
- [Testing](testing/index.md) — business-process test automation
- [Platform & Tooling](platform-and-tooling/index.md) — parent POMs, starters, CLI, build/release tooling
