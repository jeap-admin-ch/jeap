# Process Archive Reader Library

## What is this?

The Process Archive Reader Library at
[jeap-process-archive-reader](https://github.com/jeap-admin-ch/jeap-process-archive-reader) provides a simple
abstraction to read Avro/binary archive data from object storage.

## Documentation

See [jeap-process-archive-reader](https://jeap-admin-ch.github.io/docs/building-blocks/libraries/jeap-process-archive-reader/)
for its documentation.
