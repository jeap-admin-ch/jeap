# MessageProcessingFailed Event

## Overview

Every [message](../index.md) that cannot be processed must be wrapped in a **MessageProcessingFailedEvent** and handed over to the [Error Handling Service](error-handling-service.md). The MessageProcessingFailedEvent is itself a valid [domain event](../message-types.md). It contains the following references:

- The message that caused the error, given by a Kafka topic, the partition, and the offset of the message.
- An error case, given by an application-specific error code and an error type (permanent, temporary, or unknown).

It also contains a payload with the following fields:

- The value of the message that caused the error
- The key of the message that caused the error
- An error message
- A general error description (optional). Depending on the needs of the application, this can carry different kinds of information such as descriptions or links.
- The Java stack trace as a string (optional)
- A hash of the Java stack trace (optional)

The value and the key are transmitted as byte arrays and contain exactly the message as it was originally stored in Kafka. Usually this should be an object serialized with Avro, including a reference to a schema in the schema registry. However, if an invalid message ended up on the queue and therefore could not be deserialized, these fields contain the invalid object.

```avro
@namespace("ch.admin.bit.jeap.messaging.avro.errorevent")
protocol MessageProcessingFailedEventProtocol {
	import idl "DomainEventBaseTypes.avdl";

	record MessageProcessingFailedPayload {
		bytes originalMessage;
		union{null, bytes} originalKey = null;
		string errorMessage;
		union{null, string} errorDescription = null;
		union{null, string} stackTrace = null;
		union{null, string} stackTraceHash = null;
		union{null, FailedMessageMetadata} failedMessageMetadata = null;
	}

	record FailedMessageMetadata {
		union{null, string} eventId = null;
		union{null, string} idempotenceId = null;
		union{null, timestamp_ms} created = null;
		union{null, string} system = null;
		union{null, string} service = null;
		union{null, string} messageTypeName = null;
		union{null, string} messageTypeVersion = null;
		map<bytes> headers = {};
	}

	record MessageProcessingFailedReferences {
		MessageReference message;
		ErrorTypeReference errorType;
	}

	record MessageReference {
		string type;
		string topicName;
		string partition;
		string offset;
	}

	record ErrorTypeReference {
		string type;
		string temporality;
		string code;
	}

	record MessageProcessingFailedEvent {
		ch.admin.bit.jeap.domainevent.avro.AvroDomainEventIdentity identity;
		ch.admin.bit.jeap.domainevent.avro.AvroDomainEventType type;
		ch.admin.bit.jeap.domainevent.avro.AvroDomainEventPublisher publisher;
		MessageProcessingFailedReferences references;
		MessageProcessingFailedPayload payload;
		union{null, string} processId = null;
		string domainEventVersion;
	}
}
```

Source: [jeap-messaging / jeap-messaging-avro-errorevent / MessageProcessingFailedEvent.avdl](https://github.com/jeap-admin-ch/jeap-messaging/blob/main/jeap-messaging-avro-errorevent/src/main/avro/MessageProcessingFailedEvent.avdl).

## Integration

MessageProcessingFailedEvents are automatically generated by the [Error Handler of the jEAP Messaging Library](error-handler-of-the-jeap-messaging-library.md) and sent to a configurable Kafka topic. If the exception implements the interface `ch.admin.bit.jeap.messaging.avro.errorevent.MessageHandlerExceptionInformation`, the information from the exception is written into the error event.

## Example

The [jme-messaging-example](https://github.com/jme-admin-ch/jme-messaging-example) uses MessageProcessingFailedEvents. If the receiver [jme-messaging-subscriber-service](https://github.com/jme-admin-ch/jme-messaging-example/tree/main/jme-messaging-subscriber-service) cannot process a message, it generates a MessageProcessingFailedEvent, which is processed by [jme-messaging-error-scs](https://github.com/jme-admin-ch/jme-messaging-example/tree/main/jme-messaging-error-scs). This is based on the jEAP error handler.
